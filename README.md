# Toza Gilam

Gilam yuvish xizmati uchun buyurtmalarni boshqarish ilovasi. Telefon va kompyuterda ishlaydi, o'rnatish talab qilinmaydi.

## Imkoniyatlar
- **Yangi buyurtma:** mijoz, telefon, manzil, gilamlar (turi, eni × bo'yi). Maydon (m²) va summa avtomatik hisoblanadi. Yetkazib berish narxi va chegirma kiritiladi.
- **Holatlar:** Qabul qilindi → Yuvilmoqda → Quritilmoqda → Tayyor → Topshirildi.
- **To'lov:** to'langan yoki to'lanmaganini belgilash, qarzdorlik summasini ko'rish.
- **Bosh sahifa:** bugungi buyurtmalar, jarayondagilar, oylik tushum, to'lanmagan summa.
- **Qidiruv va filtr:** ism, telefon yoki № bo'yicha.
- **Mijoz bilan aloqa:** bitta tugma bilan qo'ng'iroq qilish yoki tayyor matnli SMS yuborish.
- **Chek:** buyurtma chekini matn sifatida nusxalash va Telegram orqali yuborish.
- **Sozlamalar:** xizmat turlari va 1 m² narxi, korxona nomi, telefon.
- **Zaxira:** ma'lumotlarni nusxalash va qayta tiklash, Excelga jadval sifatida o'tkazish.
- **Namuna:** ilovani sinab ko'rish uchun namuna buyurtmalar. Ularni bitta tugma bilan o'chirish mumkin.

## Ishga tushirish
`index.html` faylini brauzerda oching. Yoki GitHub Pages'ni yoqing: Settings → Pages → Branch.

Ma'lumotlar shu qurilmadagi brauzerda (localStorage) saqlanadi. Zaxira nusxani muntazam yuklab oling.
